Findings 概览

Critical

Windows 更新失败路径会先进入关闭逻辑并可直接 panic

restartExecutable() 先调用 shutdown.Shutdown()，而 Shutdown() 假定 logger 已初始化。go test ./internal/update -run TestRestartExecutableWindowsDoesNotExitWhenRestartFails -count=1 本轮稳定复现空指针。

High

AI Profile 双轨主线只做到了执行配置切换

当前运行时只消费 base_url/api_key/channel_type/model/use_local_default，没有把 AI 输出变成文档承诺的“方案对象 + 设置页元数据 + 可消费配置方案”。

High

AI task 取消与后台生命周期未收口

AITaskStartAsync() 使用 context.Background() 启动 goroutine，AITaskCancel() 只改 task 行，不取消正在运行的步骤。go test ./internal/server/handlers -run TestCancelAITaskHandlerMarksTaskCanceled -count=20 稳定复现 step 仍为 running。

Medium

当前宿主不足以证明完整发布闭环

后端构建可过，但 Node / socket / Linux / Docker 相关验证仍受宿主限制，意味着部分关键路径仍需在更完整环境中补证。
